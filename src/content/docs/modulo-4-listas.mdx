Hasta ahora cada dato vivía en una variable. Cuando son muchos (8 notas, 12 temperaturas), una **lista** los guarda todos bajo un mismo nombre y te deja recorrerlos con un ciclo.

## Lo esencial de las listas

```python
notas = [5.5, 4.0, 6.2]    # lista con 3 elementos
notas[0]                    # 5.5  (el primero tiene índice 0)
notas[-1]                   # 6.2  (índice negativo: desde el final)
len(notas)                  # 3
notas.append(7.0)           # agrega al final -> [5.5, 4.0, 6.2, 7.0]
notas[1] = 4.5              # reemplaza el elemento del índice 1
```

Los índices válidos van de `0` a `len(lista) - 1`. Pedir `notas[len(notas)]` es un `IndexError`.

### Leer datos y guardarlos en una lista

Es el patrón de acumulador, pero con una lista que parte vacía:

```python
n = int(input())
numeros = []
for _ in range(n):
    numeros.append(int(input()))
```

### Dos formas de recorrer

| Forma | Cuándo usarla |
| --- | --- |
| `for x in lista:` | Solo necesitas **leer** cada valor |
| `for i in range(len(lista)):` | Necesitas el **índice** (para modificar, para mirar vecinos, para mostrar la posición) |

<PythonTutor code={`
numeros = [4, 7, 2]
suma = 0
for i in range(len(numeros)):
    numeros[i] = numeros[i] * 2
    suma = suma + numeros[i]
print(numeros, suma)
`} />
