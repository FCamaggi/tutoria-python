## Cómo se evalúa un `if`

Python revisa las condiciones **de arriba hacia abajo** y ejecuta **solo el primer bloque** cuya condición sea `True`. El resto se salta.

```python
if nota >= 6.0:
    print("Excelente")
elif nota >= 4.0:
    print("Aprobado")
else:
    print("Reprobado")
```

:::caution[Trampa clásica]
El orden importa. Si pones `nota >= 4.0` primero, un 6.5 imprime "Aprobado" y nunca llega a "Excelente".
:::

## Condicionales anidados

Un `if` puede contener otro `if`. El de adentro **solo se evalúa si se cumplió el de afuera**. La indentación indica a qué `if` pertenece cada `else`.

```python
if descuento >= 30:
    if precio_final >= 50000:
        print("Descuento importante, precio alto")
    else:
        print("Descuento importante, precio bajo")
else:
    print("Descuento pequeño")
```

:::tip[¿Anidar o dos if separados?]
Anida cuando la segunda pregunta **depende** de la primera (en el ejemplo, solo importa el precio final si el descuento es importante). Usa dos `if` separados cuando las preguntas son **independientes** y las dos deben responderse siempre.
:::

<Quiz
	code={`x = 15
if x > 10:
    if x > 20:
        print("A")
    else:
        print("B")
else:
    print("C")`}
	options={[
		{ text: 'A', explanation: 'x > 10 es cierto, pero el if de adentro pregunta x > 20, y 15 no lo cumple.' },
		{ text: 'B', correct: true, explanation: 'Entra al primer if (15 > 10), y en el de adentro 15 > 20 es falso, por lo que se ejecuta su else.' },
		{ text: 'C', explanation: 'Ese else pertenece al if de AFUERA (x > 10), que sí se cumplió. Por eso nunca se ejecuta.' },
	]}
/>

<Quiz
	code={`a = 3
if a > 5:
    if a > 10:
        print("X")
else:
    print("Y")`}
	options={[
		{ text: 'No imprime nada', explanation: 'El else está alineado con el if de afuera: se ejecuta cuando a > 5 es falso, y 3 > 5 es falso.' },
		{ text: 'X', explanation: 'Para llegar a "X" primero debería cumplirse a > 5.' },
		{ text: 'Y', correct: true, explanation: 'El else queda a la altura del primer if, así que le pertenece a él. Como 3 > 5 es falso, se ejecuta el else y se imprime Y.' },
	]}
/>
