El ciclo `for` se usa cuando **sabemos de antemano cuántas veces** queremos repetir un bloque.

## La trampa de `range(inicio, fin, paso)`

Regla de oro para la prueba: **el número `fin` NUNCA se incluye**.

- `range(5)` genera `0, 1, 2, 3, 4` (5 números, partiendo del 0).
- `range(1, 5)` genera `1, 2, 3, 4`.
- `range(10, 0, -2)` genera `10, 8, 6, 4, 2`.

### Visualízalo en cámara lenta

Haz clic en **Next >** para ver cómo cambian `i` y el acumulador `suma` en cada vuelta:

<PythonTutor code={`
suma = 0
for i in range(1, 5):
    suma = suma + i
print("Total:", suma)
`} />

## Práctica: Laboratorio 3 (ciclos for)

Cuatro patrones que verás una y otra vez dentro de un `for`:

| Patrón | Se prepara antes del ciclo | Dentro del ciclo |
| --- | --- | --- |
| Contador | `cantidad = 0` | `cantidad += 1` si se cumple algo |
| Acumulador | `suma = 0` | `suma += x` |
| Máximo / mínimo | `maximo = primer valor` | `if x > maximo: maximo = x` |
| Filtro | nada | `if` que decide si se usa el valor |

Cuando se leen datos, el `for` solo repite la lectura: `for _ in range(n): x = int(input())`. El `_` indica que no necesitas el contador.

### 1. Recorridos numéricos

3. La suma de todos los números del intervalo.
