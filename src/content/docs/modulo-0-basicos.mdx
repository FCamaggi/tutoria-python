## Variables y tipos

Una variable es un nombre que apunta a un valor. Los tipos que más vas a usar:

| Tipo    | Ejemplo        | Para qué sirve          |
| ------- | -------------- | ----------------------- |
| `int`   | `edad = 20`    | Números enteros         |
| `float` | `nota = 5.5`   | Números con decimales   |
| `str`   | `nombre = "Ana"` | Texto                 |
| `bool`  | `aprobado = True` | Verdadero o falso    |

## La trampa de `input()`

`input()` **siempre devuelve un `str`**. Si necesitas un número, conviértelo:

```python
edad = input()       # "20" (texto)
edad = int(input())  # 20 (número)
```

Si sumas sin convertir, `"20" + 1` lanza un `TypeError`.

## Práctica: Guía 1 (instrucciones secuenciales)

Estos ejercicios son todos "leer datos → calcular → imprimir". La salida debe ser **exacta**, así que dos recordatorios:

- Lo que viene de `input()` es texto: conviértelo con `int()` o `float()` según corresponda.
- Para mostrar decimales fijos usa un f-string con formato: `f"{valor:.2f}"` imprime 2 decimales y `f"{valor:.1f}"`, uno. Solo cambia cómo se **muestra**, no el valor.

```python
promedio = 13 / 3
print(promedio)             # 4.333333333333333
print(f"{promedio:.2f}")    # 4.33
```
