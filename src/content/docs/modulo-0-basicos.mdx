## Variables y tipos

Una variable es un nombre que apunta a un valor. Los tipos que más vas a usar:

| Tipo    | Ejemplo        | Para qué sirve          |
| ------- | -------------- | ----------------------- |
| `int`   | `edad = 20`    | Números enteros         |
| `float` | `nota = 5.5`   | Números con decimales   |
| `str`   | `nombre = "Ana"` | Texto                 |
| `bool`  | `aprobado = True` | Verdadero o falso    |

## La trampa de `input()`

`input()` **siempre devuelve un `str`**. Si necesitas un número, conviértelo:

```python
edad = input()       # "20" (texto)
edad = int(input())  # 20 (número)
```

Si sumas sin convertir, `"20" + 1` lanza un `TypeError`.
