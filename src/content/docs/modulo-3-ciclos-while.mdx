El `while` se usa cuando **no sabemos cuántas vueltas** va a dar el ciclo: repite mientras la condición sea `True`.

## La condición se vuelve a evaluar en cada vuelta

<PythonTutor code={`
n = 3
while n > 0:
    print(n)
    n = n - 1
print("Despegue")
`} />

Fíjate que después de cada vuelta Python **vuelve a la línea del `while`** y revisa la condición otra vez.

## Práctica: Laboratorio 4 (de for a while y de while a for)

Todo `for` sobre `range` se puede escribir como `while`, y viceversa (siempre que el `while` cuente de a pasos fijos). Los tres elementos del ciclo no desaparecen, solo cambian de lugar:

| | `for` | `while` |
| --- | --- | --- |
| Inicio | dentro de `range(inicio, ...)` | línea **antes** del ciclo: `i = inicio` |
| Condición | el límite de `range` (**no incluido**) | `while i < fin` (o `<=`) |
| Paso | el tercer valor de `range` | línea **al final** del cuerpo: `i = i + paso` |

```python
for i in range(2, 9, 3):      # 2, 5, 8
    print(i)

i = 2                         # inicio
while i < 9:                  # condición: el límite no se incluye
    print(i)
    i = i + 3                 # paso (siempre al final)
```

<PythonTutor code={`
i = 2
suma = 0
while i < 9:
    suma = suma + i
    i = i + 3
print(suma)
`} />
